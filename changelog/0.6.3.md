## steps: link a diagram and a code block

A new `steps` block links a `flow`, `state` or `tree` diagram to a code block in the same panel. Each line names an item of the diagram, the code lines it stands for and a short note (#440, #461):

````markdown
```steps
Gateway 1: The request comes in.
Auth 2: Check the user.
Service 3-4: The service runs and returns the result.
```
````

- **On the page:** click an item, or press Enter or Space on it, and its lines get a box with the note above them; the item and its edges light up. Click a line number to select the step that covers it. A bar above the pair has Previous, Next, the step count and a short hint; the arrow keys move and Esc clears.
- **Layout:** the diagram and the code sit side by side, in the order you wrote them, when the block is about 720px wide or more. Narrower, they stack with the diagram on top. Long lines wrap.
- **Print, PNG, PDF and no script:** every step is numbered on its item and beside its first line, and a numbered list of the steps follows the pair.
- **Code only:** leave the diagram out and the block walks through the code step by step.
- `am render` reports each mistake with its draft line: an item that is not in the diagram, a range outside the code, overlapping ranges, a missing code block, and more. See `am help steps`.

## Fixes

- **Copy buttons:** Copy source and a code block's Copy no longer claim a copy that did not happen. When the clipboard refuses, the button says "Copy failed" in the page language (#447 by @SU-AN-coder, #457).
- **HTML sanitizers:** page styles no longer contain text that looks like a tag, so a viewer that sanitizes HTML, such as DeepSeek Harness's document preview, keeps the page's styling (#452, #456).
- **tree:** long words such as IPs and emails wrap inside their box instead of running into the next column. The toolbar no longer covers the page header, and a copied `Lead:` label is dropped (#455).
- **One-column sheets:** a `cols: 1` sheet stays in one column between 761px and 1100px wide, instead of using half the width (#459).
- **Skill:** when a page presents content the user already has and did not ask to summarize, the skill keeps every section (#432, #449 by @mojunzi).

**Full list:** #447, #449, #455, #456, #457, #459, #461.

## steps：把圖和程式碼塊連起來

新的 `steps` 塊把同一面板裡的 `flow`、`state` 或 `tree` 圖和一個程式碼塊連起來。每一行寫圖裡的一個項目、它對應的程式碼行和一句說明（#440、#461）：

````markdown
```steps
Gateway 1: 請求進來。
Auth 2: 檢查使用者。
Service 3-4: 服務執行，再把結果返回。
```
````

- **在頁面上**：點選圖中的項目（或在項目上按 Enter、空格），對應的程式碼行會被框出，框上方顯示說明，項目和它的連線一起高亮。點選行號會選中覆蓋該行的那一步。圖和程式碼上方有一條欄，帶“上一步”“下一步”、步數和一句簡短提示；方向鍵切換，Esc 取消選擇。
- **排版**：塊寬約 720px 以上時，圖和程式碼按你書寫的先後並排；更窄時上下堆疊，圖在上。長行會折行。
- **列印、PNG、PDF 和沒有指令碼時**：每一步的編號標在它的圖項目上和它的第一行旁，圖和程式碼下方有一張編號的步驟列表。
- **只有程式碼**：不寫圖時，這個塊就是對程式碼的逐步講解。
- `am render` 會帶稿件行號報告每個錯誤：項目不在圖裡、範圍超出程式碼、兩個範圍重疊、缺少程式碼塊等。完整寫法見 `am help steps`。

## 修復

- **複製按鈕**：“複製源稿”和程式碼塊的“複製”不再在沒複製成功時顯示已複製。剪貼板拒絕時，按鈕用頁面語言顯示“複製失敗”（@SU-AN-coder 的 #447、#457）。
- **HTML 清理器**：頁面樣式裡不再出現像標記的文字，所以會清理 HTML 的查看器（例如 DeepSeek Harness 的檔案預覽）不會丟掉頁面樣式（#452、#456）。
- **tree**：IP、郵箱這類長詞在自己的框裡折行，不再伸進下一欄。工具欄不再擋住頁面標題，複製時多出的 `Lead:` 標記也去掉了（#455）。
- **單欄 sheet**：`cols: 1` 的 sheet 在 761px 到 1100px 寬時保持單欄，不再只佔一半寬度（#459）。
- **skill**：頁面展示使用者已有、且沒有要求總結的內容時，skill 會保留每一節（#432、@mojunzi 的 #449）。

**完整列表**：#447、#449、#455、#456、#457、#459、#461。
