## steps: walk through a diagram, no code needed

0.6.3 linked a diagram to code. Most explanations have no code: an order lifecycle, a deploy pipeline, a state machine. Now a `steps` block in a panel with a `flow`, `state` or `tree` diagram and no code block gives each step an explanation (#465):

````markdown
```flow
Cart -> Pay -> Ship
```

```steps
Cart: The customer fills the cart.
Pay: The payment goes through.
Ship: The warehouse sends the parcel.
```
````

- **On the page:** the diagram and a numbered list of the explanations sit side by side, in the order you wrote them; on a narrow screen they stack with the diagram on top. Click an item or an explanation, or press Enter or Space on either, and the item, its edges and its explanation light up. Previous, Next and the arrow keys move, and the current explanation scrolls into view. Esc clears.
- **Print, PNG, PDF and no script:** every step is numbered on its item, beside the numbered list.
- **Writing it:** each line is `<item>: <explanation>`, with no line numbers. `am render` reports an item that is not in the diagram, and says so when the step looks like it was written with lines. A panel with code works as in 0.6.3.

## Fix

- **steps:** on a narrow screen, a diagram stacked above its code was pushed to the right by its expand button. It is centred again, like any other diagram (#465).

**Full list:** #465.

## steps：不寫程式碼，也能一步一步講一張圖

0.6.3 把圖和程式碼連了起來。但很多講解沒有程式碼，比如一筆訂單的生命週期、一條部署流水線、一個狀態機。現在，面板裡有 `flow`、`state` 或 `tree` 圖而沒有程式碼塊時，`steps` 塊給每一步配一句講解（#465）：

````markdown
```flow
Cart -> Pay -> Ship
```

```steps
Cart: 顧客把商品放進購物車。
Pay: 支付完成。
Ship: 倉庫把包裹寄出。
```
````

- **在頁面上**：圖和帶編號的講解列表按你書寫的先後並排；窄屏時上下堆疊，圖在上。點選圖中的項目或某條講解（或在兩者上按 Enter、空格），項目、它的連線和那條講解一起高亮。“上一步”“下一步”和方向鍵切換，當前講解會滾進視野；Esc 取消。
- **列印、PNG、PDF 和沒有指令碼時**：每一步的編號標在它的圖項目上，旁邊是帶編號的講解列表。
- **寫法**：每行寫 `<項目>: <講解>`，不帶行號。`am render` 會報告不在圖裡的項目；如果這一步看起來是帶著行號寫的，也會提示。有程式碼的面板和 0.6.3 一樣。

## 修復

- **steps**：窄屏上下排時，圖會被它的展開按鈕擠到右邊。現在和其他圖一樣居中（#465）。

**完整列表**：#465。
