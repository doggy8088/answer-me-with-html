## Send a page to a chat app: am export

Discord, Telegram, Slack and WeChat show an `.html` file as source. `am export` turns a rendered page into files they show (#350, #354):

```bash
am export page.html --pdf page.pdf     # A4, the page's own print rules
am export page.html --png out/         # out/page-1.png, out/page-2.png ...
```

- `--png` renders at 1200 CSS px wide and 2x, hides the toolbar, the reply and remark controls and the new-version notice, and cuts the page into slices no taller than 1800 CSS px. A cut falls in a gap between panels.
- Exporting into the same folder again removes the `<page-name>-<n>.png` slices it did not write this time, so a shorter page leaves no old slices behind. Other files stay. A slice that is the input page, or that cannot be removed, is left in place and reported (#362, #363).
- It needs Chrome, Chromium or Edge (`AM_CHROME` sets the path) and Node.js 22 or later.

## Sort and filter a table

Write `{table sort}` right after a Markdown table, and the reader clicks a header to sort it. `{table filter}` adds a text filter over every cell; `{table sort filter}` gives both (#357, #365).

- Columns of numbers, `1,200`, `$900`, `12%` or ISO dates sort by value, including integers larger than 2^53. Other columns sort as text.
- The controls work from the keyboard, are hidden in print and in PDF/PNG export, and do not appear without JavaScript. A table without the attribute stays static.
- A `<script>` in an `html` or `svg` block cannot run under the page's Content-Security-Policy. `am render` now warns about it, with the draft line.

## Video narration from your own audio files

`am video draft.md --audio-map lines.json` takes the narration from audio files you already have, with no speech server: the JSON maps each narration line to a file, `{"First the client sends SYN.": "audio/01.mp3"}` (#356, #366).

- Relative paths start at the map file's folder. A narration line without a key, or a missing file, stops the render and names it.
- 16-bit PCM WAV works as is; other WAV encodings and other formats need ffmpeg. Clips get the same silence trimming and speech cache as `--voice local`, and the cache notices a changed file.
- `--audio-map` cannot be combined with an explicit `--voice`. A command-line TTS source (#356) is still to come.

## Fewer crossings in flow diagrams, and a warning for the rest

- `flow` and `er` diagrams no longer draw a crossing that swapping two neighbouring nodes removes. Before, two edges that left one node kept the order of the draft and could cross (#369).
- When a `flow` edge still runs through another node or another edge's label, `am render` warns with the draft line and a way out: the other direction when it draws the diagram clean (```` ```flow TB ````), otherwise a split into an overview and a detail diagram. The page is still written (#378).
- The check follows the curve the page draws, not the layout points, so it matches what the reader sees (#382, #384).

## Other changes

- **Claude Code plugin:** the plugin no longer ships with a `node_modules` folder, so it is no longer turned off in a Claude Code desktop SSH session ("has a symbolic link, node_modules/.bin/esbuild"). Run `claude plugin update answer-me-with-html@answer-me-with-html` (#361, #368).
- **`am serve`:** a page opened over http keeps its answers, comments and remarks on the server, so a phone that discards a background tab no longer loses them (#322, #343).
- **Themes:** every installed theme appears in the page's theme picker, not only the default one (#348, #353).
- **flow:** a literal `\n` in a node or edge label breaks the line, as agents used to Mermaid write it (#347, #352).
- **File names:** page and draft files are named with ASCII letters and digits only, at most 24 characters, so a ctrl-click in Windows Terminal or a wrapping TUI opens the whole path. A title with no ASCII gives `page-<time>.html`, so a draft can name its file with `file: tcp-handshake` in the front matter (#344, #351, #379, #383).
- **Korean:** Korean pages break lines between words, not between syllables. A status badge with a long note wraps beside its icon instead of widening the table (#355).
- **Skill:** commands use `${CLAUDE_SKILL_DIR}` again, and other hosts are told to replace it with the skill's directory, which fixes `Cannot find module '/scripts/am.mjs'` in opencode (#326, #327).
- **Dependencies:** dagre 3.1.3 and marked 18.1.2 (#376, #377).
- **Docs:** INSTALL.md says there is no npm package and that `-a '*'` reports agents without global skills as failed, which is expected (#345). The reference says an automatic panel ID can name another panel after a new render, so give panels letters before `am patch --panel B` (#346). SKILL.md says the ask count and word limits are advice; the CLI checks only 2 to 6 options (#358, #360).

## 把頁面發到聊天工具：am export

Discord、Telegram、Slack 和微信會把 `.html` 檔案顯示成原始碼。`am export` 把渲染好的頁面轉成它們能直接顯示的檔案（#350、#354）：

```bash
am export page.html --pdf page.pdf     # A4，按頁面自己的列印樣式
am export page.html --png out/         # out/page-1.png、out/page-2.png ……
```

- `--png` 按 1200 CSS px 寬、2 倍分辨率渲染，隱藏工具欄、回覆和標註控制項以及新版本提示，把頁面切成每張不超過 1800 CSS px 高的圖。切口落在面板之間的空隙裡。
- 再次匯出到同一個目錄時，會刪掉這次沒有重新寫入的 `<頁面名>-<n>.png` 切片，所以頁面變短後不會留下舊圖。其他檔案不動。如果某個切片就是輸入的頁面，或者刪不掉，就保留原樣並給出提示（#362、#363）。
- 需要 Chrome、Chromium 或 Edge（用 `AM_CHROME` 指定路徑），以及 Node.js 22 或更高版本。

## 表格排序和篩選

在 Markdown 表格後面緊接著寫 `{table sort}`，讀者點表頭就能排序。`{table filter}` 加一個對所有單元格的文字篩選框；`{table sort filter}` 兩個都要（#357、#365）。

- 數位、`1,200`、`$900`、`12%` 或 ISO 日期組成的列按數值排序，超過 2^53 的整數也準確。其他列按文字排序。
- 控制項可以用鍵盤操作，列印和 PDF/PNG 匯出時隱藏，沒有 JavaScript 時不出現。沒寫這個屬性的表格保持靜態。
- `html` 或 `svg` 塊裡的 `<script>` 在頁面的 Content-Security-Policy 下無法執行，`am render` 現在會給出警告，並指出草稿裡的行號。

## 用現成的音訊檔案做影片旁白

`am video draft.md --audio-map lines.json` 直接用你已有的音訊檔案做旁白，不需要語音服務：JSON 裡把每行旁白對應到一個檔案，例如 `{"First the client sends SYN.": "audio/01.mp3"}`（#356、#366）。

- 相對路徑從對應檔案所在的目錄算起。某行旁白沒有對應的鍵、或者檔案不存在時，渲染會停下並指出是哪一行。
- 16-bit PCM WAV 可以直接用，其他 WAV 編碼和其他格式需要 ffmpeg。音訊和 `--voice local` 一樣會裁掉首尾靜音、使用語音快取，檔案改動後快取會重新讀取。
- `--audio-map` 不能和明確的 `--voice` 同時使用。命令列 TTS（#356）還沒做。

## flow 圖交叉更少，剩下的會給出提示

- `flow` 和 `er` 圖裡，交換兩個相鄰節點就能消除的交叉不會再畫出來。以前從同一個節點出發的兩條連線按草稿順序排列，可能互相交叉（#369）。
- `flow` 的連線仍然穿過別的節點或別的連線標記時，`am render` 會帶上草稿行號給出提示和解決辦法：換個方向能畫乾淨時建議換方向（```` ```flow TB ````），否則建議拆成總覽圖和細節圖。頁面照常生成（#378）。
- 檢查按頁面實際畫出的曲線進行，而不是按佈局給出的折點，所以和讀者看到的一致（#382、#384）。

## 其他改動

- **Claude Code 外掛：** 外掛裡不再帶 `node_modules` 目錄，所以在 Claude Code 桌面版的 SSH 會話裡不會再被關掉（"has a symbolic link, node_modules/.bin/esbuild"）。執行 `claude plugin update answer-me-with-html@answer-me-with-html` 即可（#361、#368）。
- **`am serve`：** 通過 http 打開的頁面，回答、評論和標註儲存在伺服器端，手機回收後台標記頁後也不會丟（#322、#343）。
- **主題：** 頁面的主題切換器裡會列出所有已安裝的主題，不只是預設主題（#348、#353）。
- **flow：** 節點或連線標記裡的 `\n` 會換行，按 Mermaid 習慣寫的草稿可以直接用（#347、#352）。
- **檔名：** 頁面和草稿檔名只用 ASCII 字母和數位，最長 24 個字元，在 Windows Terminal 裡 ctrl+點選、或者在會自動折行的 TUI 裡點選，都能打開完整路徑。沒有 ASCII 字元的標題生成 `page-<時間>.html`，這時可以在草稿 frontmatter 裡寫 `file: tcp-handshake` 指定檔名（#344、#351、#379、#383）。
- **韓文：** 韓文頁面在詞與詞之間換行，不再把一個詞從音節中間拆開。帶長備註的狀態標記會在圖標旁邊換行，不再把表格撐寬（#355）。
- **Skill：** 命令裡重新使用 `${CLAUDE_SKILL_DIR}`，並告訴其他宿主把它換成 skill 所在的目錄，修復了 opencode 裡的 `Cannot find module '/scripts/am.mjs'`（#326、#327）。
- **依賴：** dagre 3.1.3、marked 18.1.2（#376、#377）。
- **檔案：** INSTALL.md 說明沒有 npm 包，並說明用 `-a '*'` 時不支援全域 skill 的 agent 會顯示安裝失敗，這是正常的（#345）。參考文件說明重新渲染後自動編號的面板字母可能指向另一個面板，所以用 `am patch --panel B` 之前先給面板寫上字母（#346）。SKILL.md 說明提問數量和字數限制只是建議，CLI 只檢查每個提問 2 到 6 個選項（#358、#360）。
