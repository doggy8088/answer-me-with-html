## Theme catalog

Themes now have a home: **[answer-me-with-html.com/themes](https://answer-me-with-html.com/themes/)**. Each theme has its own page with a live preview in light and dark.

```
am theme add comic --use
```

- `am theme add <name>` downloads a theme from the catalog, checks its size, sha256, colors and contents, and saves it. `--use` also makes it your default theme.
- `am theme list`, `am theme update` and `am theme remove`. `update` never overwrites a theme file you edited.
- Only catalog names are accepted, never a URL. A theme may not load anything from the network, so pages keep working offline.
- The first three themes: **comic**, **manga** and **pop**. Their headings use the Bangers font, which the page carries inside itself.
- On an older version, the theme page shows a one-line manual install.

## Themes can restyle diagrams

New optional diagram tokens let a theme change nodes, edges, sequence actors, notes, highlights and shadows: fill, stroke, line width, corner radius and hard shadows. Every token defaults to the current look, so built-in themes are unchanged. See "Diagram tokens" in the [reference](https://github.com/doggy8088/answer-me-with-html/blob/main/docs/reference.md).

## Replies

## 主題庫

主題有了自己的地方：**[answer-me-with-html.com/zh/themes](https://answer-me-with-html.com/zh/themes/)**。每個主題都有單獨的頁面，可以實時預覽亮色和暗色。

```
am theme add comic --use
```

- `am theme add <名字>` 從主題庫下載主題，核對大小、sha256、配色和內容後儲存。加 `--use` 會同時設成預設主題。
- 另有 `am theme list`、`am theme update` 和 `am theme remove`。`update` 不會覆蓋你改過的主題檔案。
- 只接受主題庫裡的名字，不接受網址。主題不能從網上載入任何東西，所以頁面離線也能正常打開。
- 首批三個主題：**comic（漫畫）**、**manga（日漫）**、**pop（波普）**。標題用 Bangers 字體，字體內嵌在頁面裡。
- 舊版本在主題頁上可以看到一行手動安裝命令。

## 主題可以改圖表了

新增一組可選的圖表變數，主題可以改節點、連線、時序圖的參與者、註解框、高亮和陰影：底色、線色、線寬、圓角和硬陰影。每個變數的預設值都是現在的樣子，內建主題的外觀不變。詳見[參考文件](https://github.com/doggy8088/answer-me-with-html/blob/main/docs/reference.zh-TW.md)的"圖表變數"一節。
