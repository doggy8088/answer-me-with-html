<!-- release 0.6.2 2026-11-20 -->

## Export menu: copy as image, download PNG, save as PDF

The toolbar's Copy as image button is now an **Export** menu (#433, #442):

- **Copy as image** puts the whole page on the clipboard as a PNG.
- **Download PNG** saves the same image as a file named from the page title. The code comes from #434 by @Linuxdazhao.
- **Save as PDF** opens the browser's print dialog with the page's print styles.

Copying also works in Firefox now. When the browser, the clipboard or a policy rules copying out, the menu item is disabled and says why, instead of the button disappearing. Safari and other browsers can try it, with a note that the result is not guaranteed (#424, #425, #438). A long page stays within the browser's canvas limit, and a table or diagram that scrolls on the page no longer shows stray scrollbars in the image (#435, #436).

## am render checks path:line references

An inline code span that is only a path and a line, such as `` `src/cli.js:42` `` or `` `src/cli.js:18-30` ``, cites that file. `am render` checks it against the current folder and prints a `refs` warning with the draft line (`L12 [ref] ...`) when the file is missing, the lines go past its end, or the range runs backwards. A missing file counts only when its first folder exists here (`src/clii.js:4` when `src/` exists), so a path of another project is not checked. A page with these warnings does not open by itself, the same as with code warnings (#426, #429).

The skill also has a method for pages that explain a codebase: find the entry points, draw the modules, trace one request end to end, and cite every claim as `path:line` (#426, #427).

## api: one change across several endpoints

An `api` block can hold several HTTP and RPC endpoints that one requirement changes together. Mark endpoints, sections or fields with `+`, `-` or `~`, and the block gets the same Before / Changes / After switch as other change views. A paired `-` old and `+` new line keeps both exact definitions (#393).

## Fixes

- **Private pages:** `am render --replace` keeps a private page private when the new page gets a new file name, so a 0600 page in a shared `pages_dir` is no longer rewritten as 0644 (#443).
- **Diagram viewer:** a diagram stays sharp when you zoom in, instead of showing a stretched bitmap (#430, #441).
- **api tables:** a narrow column wraps field names and types between words (`Order|Status`, `refund_|amount`), not at any letter (#428).
- **Tests:** two races in the live-reload browser tests are fixed (#444).
- **Dependencies:** marked 18.2.0 (#437).

**Full list:** #393, #425, #427, #428, #429, #436, #437, #438, #441, #442, #443, #444.

## 匯出選單：複製為圖片、下載 PNG、儲存為 PDF

工具欄上的「複製為圖片」按鈕改成了**匯出**選單（#433、#442）：

- **複製為圖片**：把整頁作為 PNG 放進剪貼板。
- **下載 PNG**：把同一張圖片存成檔案，檔名取自頁面標題。程式碼來自 @Linuxdazhao 的 #434。
- **儲存為 PDF**：打開瀏覽器的列印對話框，使用頁面自帶的列印樣式。

Firefox 現在也能複製。瀏覽器、剪貼板或權限策略不允許複製時，選單項會變灰並說明原因，按鈕不再直接消失。Safari 等其他瀏覽器可以嘗試，同時提示效果不保證（#424、#425、#438）。很長的頁面不會超出瀏覽器的畫布上限；頁面上可橫向滾動的表格或圖表，在圖片裡不再出現多餘的滾動條（#435、#436）。

## am render 核對 路徑:行號 引用

正文裡只寫路徑和行號的行內程式碼，如 `` `src/cli.js:42` `` 或 `` `src/cli.js:18-30` ``，表示引用該檔案。`am render` 會在當前目錄裡核對：檔案不存在、行號超出檔案末尾、或範圍前大後小時，輸出帶稿件行號的 `refs` 警告（`L12 [ref] ...`）。檔案不存在時，只有它的第一級目錄在當前目錄裡存在才算警告（例如 `src/` 存在而寫了 `src/clii.js:4`），所以其他項目的路徑不檢查。有這類警告的頁面和有程式碼警告的一樣，不會自動打開（#426、#429）。

skill 裡還新增了講解程式碼庫的方法：先找入口，畫出模組，從頭到尾追一條請求，每個結論都用 `路徑:行號` 標出出處（#426、#427）。

## api：一次改動涉及多個介面

一個 `api` 塊可以放同一需求一起改動的多個 HTTP 和 RPC 介面。在介面、分區或欄位前加 `+`、`-` 或 `~`，塊上就會出現和其他改動檢視一樣的「改前 / 變更 / 改後」切換。成對的 `-` 舊定義和 `+` 新定義會各自原樣保留（#393）。

## 修復

- **私有頁面**：`am render --replace` 生成的新頁面換了檔名時，私有頁面仍保持私有，共用 `pages_dir` 裡權限 0600 的頁面不會再變成 0644（#443）。
- **圖示查看器**：放大圖表時保持清晰，不再顯示拉伸的位圖（#430、#441）。
- **api 表格**：列太窄時，欄位名和型別在詞與詞之間換行（`Order|Status`、`refund_|amount`），不會在任意字母處斷開（#428）。
- **測試**：修復 live 自動重新整理瀏覽器測試裡的兩處競態（#444）。
- **依賴**：marked 18.2.0（#437）。

**完整列表**：#393、#425、#427、#428、#429、#436、#437、#438、#441、#442、#443、#444。
