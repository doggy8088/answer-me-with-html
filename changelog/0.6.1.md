## New diagrams: state machines, UML classes and API contracts

- **`state`** draws a state machine: one `From -> To: event` per line, `[*]` for the initial and final states, and a loop for `Open -> Open: retransmit`. A TCP handshake or an order lifecycle reads as states and events instead of a generic flowchart (#388, #390).
- **`class`** draws UML class diagrams: attributes and methods, interfaces, abstract classes and enums, with inheritance, realization, composition, aggregation, association and dependency (#386, #387).
- **`api`** shows one HTTP or RPC endpoint per block: path, query and header parameters, request and response types and statuses, and a Requirement column when fields say `required` or `optional`. It shows the contract; it sends no request (#386, #387).
- `am help state`, `am help class` and `am help api` give the syntax.

## A preview under each ask option

An `ask` option can carry a preview: indent a `:::` block under it, with any component, `html` or `svg`. `ask cards` lays the options out as a grid of cards, each preview its canvas, for a choice between looks (#392, #389).

## Copy as image, and pages_dir

- **Copy as image:** a toolbar button draws the whole page into a PNG and puts it on the clipboard. It appears in Chromium on a local file, `localhost` or HTTPS; Firefox and Safari cannot draw the page reliably, so it stays hidden there. If the clipboard refuses the image, the page downloads the PNG. A screen reader hears the result (#399, #400).
- **`pages_dir`:** `am config set pages_dir ~/answers` writes pages into that folder; a relative path is inside the data directory. `am render`, `--replace`, `am theme check` and `am serve` follow it. `am clean` deletes only the page files it generated there, and a page replaced there keeps its file mode, so a private page in a shared folder stays private (#399, #400).

## Video narration from a command-line TTS: --voice cmd

`am video draft.md --voice cmd` runs the command in `AM_TTS_CMD` once per narration line, with no speech server, so it works in a sandbox that cannot listen on a port. It works with edge-tts, piper, a Kokoro CLI, or `say` outside a sandbox (#356, #401, #419):

```bash
AM_TTS_CMD='edge-tts --voice zh-CN-XiaoxiaoNeural --file {text_file} --write-media {out}' \
  am video draft.md --voice cmd --mp4
```

- `{out}` is the audio file the command writes; `{text_file}`, `{text}` and `{lang}` give it the line and its language, and the line also goes to stdin. The command runs without a shell, so narration text is never read as shell syntax.
- Clips get the same silence trimming and speech cache as the other voices. A missing program, a failed run or a silent clip stops the render and says why.

## Turkish

Pages and the video player speak Turkish: write `lang: tr` in the draft (#412).

## Layout fixes

- **Tables:** a long id or path no longer holds its column at full width and leaves the prose columns one word per line. A table short of room breaks such a word inside its cell, also in inline code and in a chart's data table (#413, #418).
- **Diagrams:** a diagram is never drawn under 0.75 of its natural width, where its text gets too small; it scrolls sideways instead. A box that hides content past an edge fades that edge, so it does not look cut off. Printed, a diagram shrinks to the page again (#414).
- **Windows scrollbars:** with classic scrollbars, some sheets fell back to the plain grid on wide screens; they now lay out as on macOS (#416).
- **flow:** no crossing is left that two moves at once would remove (#408). A change marker written before a node inside the line (`A -> + B`) is an error with the line rewritten, instead of a second box (#420).
- **sequence, tree, kv, timeline:** step numbers from 10 on keep clear of their label; a forest of top-level items draws no stray connectors; a kv grid has no empty corners; long words wrap inside timeline steps and inline code, and a two-line date keeps every dot on one line (#409, #410).
- **Dark mode:** pages tell the browser their colour scheme, so scrollbars and menus match. Links inside components (kv, timeline, tree, ask) take the theme's link colour instead of the browser's blue (#395, #398, #405, #415).
- **Claude desktop app:** a page opened there, whose host root already has its own `data-theme`, now gets its theme instead of no styles at all (#407, #411).

## 新圖表：狀態機、UML 類圖和介面定義

- **`state`** 畫狀態機：每行一條 `From -> To: event`，`[*]` 表示初始和終止狀態，`Open -> Open: retransmit` 畫成自環。TCP 握手、訂單生命週期這類內容讀起來是狀態和事件，而不是普通流程圖（#388、#390）。
- **`class`** 畫 UML 類圖：屬性和方法、介面、抽象類別和枚舉，以及繼承、實作、組合、聚合、關聯和依賴（#386、#387）。
- **`api`** 每個塊展示一個 HTTP 或 RPC 介面：路徑、查詢和請求頭參數，請求和回應的型別與狀態；欄位寫了 `required` 或 `optional` 時會顯示"必填性"一列。它只展示定義，不發送請求（#386、#387）。
- 語法見 `am help state`、`am help class` 和 `am help api`。

## 提問選項下的預覽

`ask` 的選項可以帶一個預覽：在選項下縮進寫一個 `:::` 塊，裡面可以是任何元件，也可以是 `html` 或 `svg`。`ask cards` 把選項排成卡片網格，每個預覽就是卡片的畫布，適合在幾種樣式之間做選擇（#392、#389）。

## 複製為圖片，以及 pages_dir

- **複製為圖片：** 工具欄上的按鈕把整頁畫成 PNG 並放進剪貼板。它在 Chromium 打開本地檔案、`localhost` 或 HTTPS 頁面時出現；Firefox 和 Safari 無法可靠地把頁面畫成圖片，因此在那裡保持隱藏。剪貼板拒絕圖片時，頁面會改為下載 PNG。螢幕報讀軟體會讀出結果（#399、#400）。
- **`pages_dir`：** `am config set pages_dir ~/answers` 把頁面寫到這個目錄；相對路徑按資料目錄解析。`am render`、`--replace`、`am theme check` 和 `am serve` 都跟隨它。`am clean` 在這裡只刪除它生成的頁面檔案；在這裡替換頁面時會保留原檔案的權限，共享目錄裡的私有頁面仍然是私有的（#399、#400）。

## 用命令列 TTS 做影片配音：--voice cmd

`am video draft.md --voice cmd` 對每行旁白執行一次 `AM_TTS_CMD` 裡的命令，不需要語音服務，所以在不能監聽連接埠的沙箱裡也能用。edge-tts、piper、Kokoro 命令列工具，或沙箱外的 `say` 都可以（#356、#401、#419）：

```bash
AM_TTS_CMD='edge-tts --voice zh-CN-XiaoxiaoNeural --file {text_file} --write-media {out}' \
  am video draft.md --voice cmd --mp4
```

- `{out}` 是命令寫出的音訊檔案；`{text_file}`、`{text}` 和 `{lang}` 把這行旁白和它的語言交給命令，旁白也會寫進標準輸入。命令不經過 shell 執行，旁白文字不會被當成 shell 語法。
- 音訊和其他配音來源一樣會裁掉首尾靜音、使用語音快取。找不到程式、執行失敗或生成的音訊是靜音時，渲染會停下並說明原因。

## 土耳其語

頁面和影片播放器支援土耳其語：在草稿裡寫 `lang: tr`（#412）。

## 排版修復

- **表格：** 很長的 id 或路徑不會再把所在列撐滿，把文字列擠成一行一個詞。表格空間不夠時，這類長詞會在單元格內折行，行內程式碼和圖表的資料表格也一樣（#413、#418）。
- **圖表：** 圖表不會再縮到原尺寸的 0.75 倍以下（再小文字就看不清），而是改為橫向滾動。內容超出邊緣的區域會在那一側漸隱，看起來不像被截斷。列印時圖表仍會縮回頁寬（#414）。
- **Windows 滾動條：** 使用經典滾動條時，有些頁面在寬螢幕上會退回普通網格；現在和 macOS 上一樣正常排版（#416）。
- **flow：** 需要同時行動兩處才能消除的連線交叉也不會再畫出來（#408）。變更標記寫在行中間的節點前（`A -> + B`）時會報錯並給出改好的寫法，不再多畫一個框（#420）。
- **sequence、tree、kv、timeline：** 第 10 步以後的編號不再貼住標記；多個頂層節點並排時不再畫多餘的連線線；kv 網格不再留出空角；時間線和行內程式碼裡的長詞會折行，日期折成兩行時所有圓點仍在同一行（#409、#410）。
- **深色模式：** 頁面會告訴瀏覽器自己的配色，滾動條和下拉選單隨之變深。元件裡的連結（kv、時間線、樹、提問）使用主題的連結色，不再是瀏覽器預設的藍色（#395、#398、#405、#415）。
- **Claude 桌面應用：** 在宿主根元素已經帶有自己 `data-theme` 的環境裡打開頁面，現在能正常顯示主題，而不是完全沒有樣式（#407、#411）。
